# Source Code Reference

The complete production source code for the **DroneTV AI Support & Lead Assistant** is organized in the root workspace folders:

- **Frontend Application:** [`../frontend/`](../frontend/)
  - React 19, TypeScript, Vite, React Router DOM, Axios, Lucide React, Modular CSS.
- **Backend Application:** [`../backend/`](../backend/)
  - Node.js, Express.js, TypeScript, MySQL Connection Pool, JWT, bcryptjs.
- **Database Schema & Seeds:** [`../backend/sql/`](../backend/sql/)
  - `schema.sql` and `seed.sql`.

*To create an archive for submission:*
Compress the `frontend` (excluding `node_modules` and `dist`) and `backend` (excluding `node_modules` and `dist`) folders into a ZIP file named `01_Source_Code_DroneTV.zip` and place it here.
